# Личный кабинет KIM AI School — геймификация (архитектура)

> Референс — платформа School21 (dashboard / roadmap-граф / projects / badges / skills).
> Механики переносим, **визуал остаётся светлым на бренде KIM** (`#CB172C`, Inter Tight / Manrope, белые карточки `border:1px solid #ededed`, radius 20).
> Аудитория — подростки 12–17. Тон геймификации мотивирующий, не «взрослый кодерский».

Каждая страница выкатывается отдельным коммитом, но структура (nav, схема БД, лейаут-примитивы) закладывается сразу.

## 2. Модель геймификации (термины KIM)

| S21 | KIM | Смысл |
|-----|-----|-------|
| XP / Level | **Опыт (XP) / Уровень** | XP за пройденные уроки, модули, проекты. Уровень — из накопленного XP. |
| Coins | **KIM-коины** | Валюта наград (квесты, серии). Тратится позже (магазин наград, доп. консультация, мерч). |
| — | **Серия (streak)** | Дни подряд с активностью. Огонёк 🔥. |
| Peer Review points | **Отзыв наставника** | Оценка наставника по 4 осям (см. ниже). Не «peer», а mentor. |
| Peer feedback (Interested/Nice/Punctual/Rigorous) | **Любознательность / Аккуратность / Самостоятельность / Креатив** | 4 оси фидбека, понятные подростку. |
| Skills radar | **Радар навыков** | AI-навыки: Промптинг, Генерация изображений, Работа с текстом, Агенты/автоматизация, Данные, Этика и безопасность, Проектное мышление, Презентация. |
| Projects | **Проекты / артефакты** | Работы ученика. Канбан: Зарегистрирован → В работе → На проверке → Готово. |
| Roadmap | **Роадмап** | Граф зависимостей уроков/модулей/проектов. Статусы: закрыто / доступно / в процессе / пройдено. |
| Badges / Quests | **Достижения / Квесты** | Ачивки с рангами (бронза→платина, 1/5…5/5) + временные квесты. |

### Кривая уровней
Уровень считается из накопленного XP (хранится в коде, не в БД — легко тюнить):
`нужно_для_уровня(n) = 100 * n * (n+1) / 2` (lvl1=100, lvl2=300, lvl3=600, …).
`lib/gamification/levels.ts` → `levelFromXp(xp)`, `progressInLevel(xp)`.

### Источники XP/коинов (правила начисления)
- Урок пройден → +XP (из `lessons.xp_reward`, дефолт 50).
- Модуль закрыт → +XP бонус.
- Проект принят наставником → +XP (`projects.xp_reward`) +коины.
- Квест выполнен → XP+коины.
- Серия 7/30 дней → коины.

Все начисления пишутся в **`reward_events`** (леджер) — это же источник аналитики «контроля юзера».

## 3. Раскладка Dashboard (`/dashboard`)

Светлые карточки KIM. Сверху вниз:

```
┌ HERO ─────────────────────────────────────────────────────────┐
│ [аватар+кольцо lvl]  Имя · программа        🔥 серия N дней     │
│ Уровень 8 · XP-бар ▓▓▓▓░░░░ 2%                                  │
└───────────────────────────────────────────────────────────────┘

┌ МЕТРИКИ (5 плиток) ───────────────────────────────────────────┐
│ XP всего │ KIM-коины │ Серия │ Ближайший дедлайн │ Достижения  │
└───────────────────────────────────────────────────────────────┘

┌ ПРОДОЛЖИТЬ ОБУЧЕНИЕ (карусель) ───────────────────────────────┐
│ [след. урок] [активный проект] [рекомендованный квест] …       │
└───────────────────────────────────────────────────────────────┘

┌ Расписание / события ──────────┐ ┌ Роадмап-превью ────────────┐
│ ближайшие занятия и события     │ │ мини-граф + % пройдено      │
└─────────────────────────────────┘ └─────────────────────────────┘
```

Компоненты: `components/dashboard/gamification/*` — `HeroCard`, `MetricTile`, `ContinueCarousel`, `AgendaWidget`, `RoadmapPreview`.

## 4. Ключевые страницы (кратко)

- **Роадмап** — граф на `@xyflow/react` (react-flow) или кастомный SVG. Ноды = урок/модуль/проект, рёбра = зависимости. Клик по ноде → карточка/переход. Зум/фит-контролы как в S21.
- **Проекты** — 3 колонки-канбан + табы Текущие / Рекомендованные / Завершённые. Карточки с XP-бейджем, оценкой часов, тегом individual/module.
- **Достижения** — секции (Учёба / Активность / Проекты / Комьюнити), карточки-бейджи с рангом и залоченные с 🔒. Таб «Квесты».
- **Навыки** — радар (паучья диаграмма) + график роста XP по времени + сводка отзывов наставника.
- **Профиль** — к текущей форме добавить гейм-сводку (уровень, XP/коины, отзывы наставника).

## 5. Аналитика и контроль пользователя

Два уровня:
1. **Клиент (поведение)** — Яндекс.Метрика, счётчик `110745059`. Цели (goals) навешиваем по ходу на ключевые действия: `lesson_start`, `lesson_complete`, `project_submit`, `quest_claim`, `cta_lead`, `payment_success`. Хелпер `lib/metrika.ts → ymGoal(name, params?)`.
2. **Сервер (учебный прогресс)** — таблица `reward_events` + `user_stats.updated_at` + `user_projects.status` дают полную картину: что делал, когда, сколько XP, где застрял. Основа для будущих «целей по юзеру» и админ-дашборда.

## 6. Схема БД

Полная миграция — `supabase/gamification.sql`. Кратко новые таблицы:

- `user_stats` — xp, coins, level, streak, last_active (1:1 к profiles).
- `reward_events` — леджер начислений XP/коинов (аудит + аналитика).
- `badges` / `user_badges` — каталог ачивок + разблокировки с рангом.
- `quests` / `user_quests` — квесты + прогресс.
- `projects` / `user_projects` — проекты-артефакты + канбан-статус.
- `roadmap_nodes` / `roadmap_edges` / `user_node_status` — граф пути.
- `skills` / `user_skills` — радар навыков.
- `mentor_feedback` — отзывы наставника (4 оси).
- `events` / `user_events` — календарь/агенда.

RLS: пользователь видит/меняет свои строки; каталоги (`badges/quests/skills/projects/roadmap_nodes/events`) читаемы всеми авторизованными; админ — всё.
